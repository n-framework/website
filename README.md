# NFramework Website & Docs

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

The marketing site and documentation for NFramework, built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build).

---

## Development

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

The site is served at `http://localhost:4321` by default.

## Build

```bash
npm run build      # Build the production site into dist/
npm run preview    # Preview the production build locally
```

---

## Structure

```text
src/        - Pages, content collections, and components
public/     - Static assets served as-is
scripts/    - Build and content helper scripts
dist/       - Production build output (generated)
```
